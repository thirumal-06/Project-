# Assmeth (Android)
1. Android Studio > Open this folder; let Gradle sync (it will offer to create the wrapper).
2. Optional AI chat/correction: copy local.properties.example lines into local.properties (claude.key=...).
3. Run on your phone (USB debugging on).
4. In the app: 1) Grant permissions, 2) Allow display over other apps, 3) Battery > Unrestricted. Then tap Turn ON.
5. Turn OFF from the app or the "Turn off" button in the notification.
